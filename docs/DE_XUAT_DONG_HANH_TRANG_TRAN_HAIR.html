II. Nâng cấp & hoạt động đã làm (từ lúc bảng chi phí → hiện tại)

Các hạng mục ngoài/ bổ sung giúp tiệm vận hành thực tế và chuẩn bị lâu dài — không tính thêm phí dự án trong tài liệu này.

1. Vận hành & nghiệp vụ salon

  • Hóa đơn dịch vụ (HD) — tạo bill sau khi làm tóc; khách xác nhận/thanh toán trên web → tích điểm loyalty.
  • Báo cáo doanh thu — admin xem theo ngày / tuần / tháng; so sánh kỳ; xuất CSV chỉ Platform Admin.
  • Phân quyền 2 vai: Platform Admin (quản trị web) · Salon Admin (lịch, đơn, HĐ, xem doanh thu).
  • Platform Admin cấp / thu hồi Salon Admin trên web (/admin/tools) + Firebase claim.
  • Chuông thông báo admin — lịch thiếu HĐ, lịch chờ duyệt, đơn/HĐ chờ xử lý.
  • Tối ưu UX admin (bỏ nút re-seed dễ bấm nhầm; re-seed chỉ Platform, xác nhận gõ SEED).

2. SEO & hiện diện Google

  • Meta tiếng Việt, từ khóa địa phương (Sóc Trăng), FAQ + JSON-LD, robots.txt.
  • Sitemap động lúc build — gồm từng dịch vụ/sản phẩm.
  • File xác minh Google Search Console; meta từng trang & trang chi tiết dịch vụ.
  • Footer / schema đa kênh; liên kết web ↔ portfolio.

3. Triển khai & ổn định kỹ thuật

  • Deploy tự động: GitHub → Cloud Run (API) · Cloudflare Pages (website).
  • API production Cloud Run; Firebase/Firestore; smoke test vận hành.
  • Tài liệu vận hành: RBAC, SOP “Ai làm gì”, hướng dẫn admin.

III. Đề xuất gói hỗ trợ remote hàng tháng
